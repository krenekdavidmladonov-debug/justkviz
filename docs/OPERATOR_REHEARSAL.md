# JustKvíz — generálka před akcí

Datum: __________ Obsluha: __________ Akce/demo: __________ Verze: __________
Použijte demo nebo schválenou soukromou generálku; žádné skutečné kontakty ani testovací emaily účastníkům. U každého kroku zapište PASS/FAIL, poznámku a jméno; nezaškrtnuté = NEOVĚŘENO.

Doloženo vlastníkem: notebook fungoval, externí monitor fungoval, zvuk z notebooku fungoval. Není to potvrzení skutečného projektoru ani fyzického tisku.

| Krok | Praktický úkon a očekávaný výsledek | Výsledek / poznámka |
|---|---|---|
| 1 | Přihlaste obsluhu, otevřete konkrétní akci, vyberte správný připravený kvíz a ověřte připravené otázky. Připravte soukromou zálohu podle schváleného plánu. | |
| 2 | Spusťte moderátorský režim. Na notebooku zůstávají ovládání a soukromé odpovědi; projektor zobrazí jen veřejný výstup. | |
| 3 | Připojte skutečný projektor, zapněte rozšíření obrazovek (Windows+P), přesuňte projektorové okno a celou obrazovku. Ověřte 16:9/čitelnost ze zadní řady, bez soukromých UI. | |
| 4 | Pusťte video, pauzu, stop a opakování po chybě. Ověřte skutečný obraz i zamýšlený zvukový výstup/kabel. | |
| 5 | Pusťte audio z moderátora, pause/stop/opakování a hlasitost; po přechodu nesmí hrát stará otázka. Ověřte i znělku a ruční retry/Stop. | |
| 6 | Zobrazte obrázek otázky a až po výslovném odhalení odpověď. Zkontrolujte ořez, kontrast a vzdálené zdroje skutečné sítě v místě. | |
| 7 | Projděte přechody tlačítkem i klávesami včetně rychlého opakování. Čekejte na potvrzený obsah, neodhalujte odpověď omylem. Po krátkém výpadku sítě zkontrolujte reconnect a správnou otázku. | |
| 8 | Otevřete samostatný odkaz rozhodčího, zapište body, změňte akci a ověřte oddělení. Odvolaný/starý odkaz nesmí přijmout nový bod. | |
| 9 | Ověřte roster, bodování kol, opravu s důvodem a potvrzení průběžných výsledků; na projektoru jsou jen potvrzené týmy/body. | |
| 10 | Dokončete finální odhalení a akci, znovu otevřete historii po reloadu/novém přihlášení. Pořadí/body musí odpovídat zapsaným výsledkům. | |
| 11 | Vygenerujte hráčské odpovědní archy, stáhněte PDF a FYZICKY vytiskněte A4 dle náhledu. Ověřte měřítko, okraje, rozříznutí a dost místa; hráčský tisk neobsahuje správné odpovědi. Soukromé klíče držte mimo účastníky. | |
| 12 | Ověřte postup výpadku: Stop médií, papírové bodování, obnovení z chráněné kopie v izolaci. Před ostrým návratem porovnejte poslední potvrzený stav a rozhodněte obsluhou. | |

Pokud selže projekce/zvuk/tisk/obnova nebo se objeví soukromá odpověď/kontakt na veřejném výstupu, ostrý večer není přijat. Lokální browser test není náhradou tohoto fyzického ověření.
