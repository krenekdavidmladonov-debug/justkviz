# Public origins and release boundary

The product's primary address is https://justkviz.cz. Existing V2 Hosting aliases and historical technical Firebase identifiers are retained for compatibility; this document does not establish their current deployed state. Public registration links and approved email/Drive origins follow the source allowlists.

Public/projector clients may receive only sanitized published data. Authentication alone grants no administrative authority. Deployments, live data writes, email activation, secrets and IAM require concrete owner approval plus current validation and a separately reviewed target. Preserve the prior compatible artifact for a bounded operator-approved rollback; never roll back databases or delete media to reverse a release.

See [custom domains](CUSTOM_DOMAIN.md) and [security](SECURITY.md). Local unit/browser/emulator evidence does not prove physical venue or cloud acceptance.
